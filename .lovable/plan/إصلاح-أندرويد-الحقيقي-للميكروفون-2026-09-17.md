# إصلاح أندرويد الحقيقي للميكروفون

## السبب المؤكد
- تعديلات الواجهة تصل عبر تحديثات التطبيق الداخلية، لكن إضافة الميكروفون الجديدة كود أصلي لا تدخل الهاتف إلا داخل APK جديد.
- مسار بناء Android الحالي يستخدم Java 17 بينما مشروع Capacitor الحالي يولّد كودًا يستهدف Java 21؛ لذلك لا يوجد ضمان أن ملف APK حديث يُبنى أصلًا.
- رقم نسخة Android ثابت عند `1`، فلا توجد علامة واضحة تميّز ملف APK الجديد عن القديم.

## التنفيذ
1. تعديل بناء Android ليستخدم Java 21، وتوليد رقم إصدار متزايد لكل بناء.
2. جعل مسار البناء يفشل بوضوح إذا لم تُسجّل إضافة `@capgo/capacitor-speech-recognition` بعد المزامنة، بدل إنتاج ملف ناقص بصمت.
3. إضافة تحقق داخل التطبيق يعرض نسخة الإضافة الأصلية الموجودة فعليًا في الهاتف، ويمنع ادعاء أن الميكروفون الأصلي متاح إذا كانت الإضافة غير موجودة في الـAPK.
4. تقوية بدء جلسة Android: فحص التوفر الحقيقي، الإذن، حالة الاستماع، ووصول مستوى صوت/نص جزئي، مع إنهاء واضح قابل لإعادة المحاولة.
5. تشغيل فحوص الويب والمزامنة، ثم محاولة بناء Android؛ إن بقيت أدوات Java/Android غير متاحة هنا سأذكر ذلك صراحة ولن أدّعي اختبار APK على هاتف.

## النتيجة المطلوبة
ملف APK جديد قابل للتمييز يحتوي الإضافة الأصلية فعلًا، ويعرض سببًا دقيقًا بدل البقاء على «تجهيز الميكروفون».
